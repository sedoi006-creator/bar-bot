Бар-бот: технологические карты для барменов
===========================================

СОСТАВ ПАКЕТА
-------------
bot.py           - сам бот (запускается всегда)
recipes.json      - база технологических карт (159 рецептов)
token.txt         - токен Telegram-бота
parse_cards.py    - парсер Excel (нужен только при обновлении карт из Excel)
requirements.txt  - список библиотек
README.txt        - этот файл

УСТАНОВКА НА НОВЫЙ КОМПЬЮТЕР
-----------------------------
1. Установите Python 3.10+ С ГАЛОЧКОЙ "Add python.exe to PATH"
   Скачать: https://www.python.org/downloads/

2. Скопируйте всю папку бар-бот в любое место
   (например, C:\бар-бот)

3. Откройте командную строку (Win+R -> cmd) и выполните:

   cd /d "ПУТЬ\К\ПАПКЕ\бар-бот"
   pip install -r requirements.txt

4. Запустите бота:

   python bot.py

   Бот работает, пока открыто это окно. Проверка: напишите
   боту в Telegram /start

АВТОЗАПУСК ВМЕСТЕ С КОМПЬЮТЕРОМ (необязательно)
------------------------------------------------
Самый простой способ - ярлык в папку "Автозагрузка":
1. Создайте файл запуска start_bot.bat рядом с bot.py:

   @echo off
   cd /d "%~dp0"
   python -X utf8 bot.py
   pause

2. Нажмите Win+R, введите shell:startup, нажмите Enter
3. Поместите в открывшуюся папку ярлык на start_bot.bat
   (правой кнопкой -> Создать ярлык)

ОБНОВЛЕНИЕ КАРТОК ИЗ EXCEL (редко)
-----------------------------------
Положите свежий Excel по старому пути или поправьте путь
в начале parse_cards.py, затем:

   python parse_cards.py

База recipes.json пересоберётся. Правки вручную
(переименования ANON_RENAMES, карточки MANUAL_CARDS) сохраняются.
